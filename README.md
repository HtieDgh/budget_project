# Расчет экономической целесообразности проекта методом линейной интерполяции

Это личный инструмент для предсказания остатка бюджета на основе текущего среднего значения расхода. Использует линейную интерполяцию для ответа на вопрос "А хватит ли мне денег при текущей скорости расхода денег из бюджета?". Результат работы программы не обладает банковской точностью, а служит лишь дополнительным инструментом перед принятием решения о изменении стратегии расхода бюджета.

## Структура репозитория

| Директория | Описание | Содержимое |
|:---|:---|:---|
| `budget/` | Основной исходный код | Модели и контроллеры |
| ├─ `Models/` | Модели данных | Модель данных Expense |
| ├─ `Services/` | Сервисы | Набор классов реализующих бизнес-логику проекта |
| └─ `Shared/` | Общие вспомогательные классы | Прочие классы, не реализующие бизнес-логику |
| `README.md` | Текущий файл | Документация проекта |

## Настройка проекта

При разработке чувствительные данные были сохранены в отдельный файл по пути `/budget/.venv/config.json`, который не отслеживается системой контроля версий. Этот файл необходим для запуска, убедитесь что он существует по заданному пути. Его структура представлена ниже:

```json
{
  "Expense": {//расход
    "Path":"\\csv\\expense.csv",
    "HeaderShema": [ "Sum", "Date", "Category" ],
    "DateFormats": [ "yyyy-MM-dd" ]
  },
  "Options": {//настройки аргументов командной строки
    "DateFormats": [ "yyyy-MM-dd" ]
  }
}
```

> [!IMPORTANT]
> Все ключи должны присутствовать. Комментарии следует убрать.

Также из индекса убран `/budget/Properties/launchSettings.json`, если он необходим, то создайте его:

```json
{
  "profiles": {
    "budget": {
      "commandName": "Project",
      "commandLineArgs": "--help"
    },
    "budget today": {
      "commandName": "Project",
      "commandLineArgs": "-s 2026-09-01 -e 2026-10-01 -b 15000"
    }
  }
}
```
